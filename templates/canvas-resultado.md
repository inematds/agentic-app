# Canvas de resultado — preencha ANTES de pensar em agente

> Uma folha por app. Se você não consegue preencher as 6 primeiras linhas, ainda não é hora de construir.

| Campo | Resposta |
|---|---|
| **Quem é a pessoa usuária** (cargo, quantas pessoas, rotina) | |
| **Que decisão ou tarefa ela faz hoje** | |
| **Quanto tempo/dinheiro isso custa hoje** (medido, não chute) | |
| **Métrica de sucesso** (um número, com prazo) | |
| **Linha de base** (o número de hoje) | |
| **Dono da métrica** (quem cobra o resultado) | |
| Dados de que a tarefa depende (sistema, tabela, dono) | |
| Ações externas envolvidas (e-mail, cadastro, pagamento) — todas passam por aprovação | |
| Regras de negócio com número (vão para `policies/` com teste) | |
| Perguntas abertas, não críticas (podem ir para busca/FAQ) | |
| Papéis: quem executa, quem aprova, quem só lê | |
| Gatilhos: clique, horário, evento | |

## Exemplo preenchido (app de referência)

| Campo | Resposta |
|---|---|
| Pessoa usuária | Ana, gestora de Operações com 12 liderados |
| Decisão | com quem conversar esta semana e o que dizer |
| Custo hoje | ~2 h/semana montando planilha; metas vencidas esquecidas |
| Métrica | % de metas vencidas com conversa em até 7 dias: de 30% para 90% em 1 trimestre |
| Dono | diretoria de Operações |
| Ações externas | e-mail de follow-up, convite de 1:1, resposta do RH |
| Regras com número | dias de férias por tempo de casa, licença parental, fracionamento |
| Perguntas abertas | holerite, home office, horário do RH |
